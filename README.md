This repository contains a Customer Churn Prediction case study, where I analyzed customer behavior to identify key factors influencing churn. The project includes data preprocessing, exploratory data analysis (EDA), feature engineering, and machine learning model development to predict customer attrition. The insights derived can help businesses take proactive measures to retain customers. The Jupyter Notebook (Customer Churn Case Study.ipynb) provides a step-by-step walkthrough of the analysis, from data cleaning to model evaluation. Feel free to explore, provide feedback, or suggest improvements!
